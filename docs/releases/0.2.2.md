## EchoFetch 0.2.2

**Fixes an update getting stuck.** Some copies of EchoFetch 0.2.0 found an update but would not install it. The Check for Updates button stayed greyed out, and the update waited for a download-engine check that had not finished. Now an update waits only for a download in progress, so it installs on its own.

Install this version by hand once: download `EchoFetch.zip`, unzip it, and drag EchoFetch into Applications, replacing the old copy. After that, new versions arrive on their own.
