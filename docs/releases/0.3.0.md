## EchoFetch 0.3.0

The download tools (yt-dlp, ffmpeg, ffprobe and Deno) are no longer packed inside the app. EchoFetch downloads them the first time it opens, checks each one against a fixed checksum, and keeps them in your Library folder. You need an internet connection on that first launch. If you already use EchoFetch, nothing changes: your tools, history and settings stay as they are.

The license and About text now name Echo App Studio.
